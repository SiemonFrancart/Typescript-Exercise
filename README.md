# Typescript-Exercise

# Exercise:Create a small game using TypeScript (in a new repository).

The game should:

    Show the player a variable or function in a textbox.

    Ask the player to complete the text, including its TypeScript type.

    Check whether their answer is correct.

    For now, compare the answers as text:

        Ignore capital letters vs. lowercase letters.

        Ignore spaces.

        Accept the answer if most of it matches the correct answer.

Keep the interface simple, clean, and easy to use, use typscript for the implementation.
